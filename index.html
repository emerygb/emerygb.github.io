02 / Research

What I'm working on

My current work focuses on extracting reliable planetary information from the light curves of transiting exoplanets observed by TESS.

PROJECT 01

Homogeneous transit fitting

Building a reproducible pipeline to model transits and compare inferred exoplanet parameters across systems.

PROJECT 02

Light-curve detrending

Investigating how different detrending approaches, including Gaussian processes, affect transit measurements.

PROJECT 03

Injection and recovery tests

Using synthetic transit signals to assess how reliably planetary parameters can be recovered from observational data.
