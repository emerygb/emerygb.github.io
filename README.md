# Personal academic website — GitHub Pages starter

A one-page academic portfolio made with HTML and CSS. No dependencies, build step, JavaScript, or paid hosting required.

## Preview the website

Open `index.html` in your browser. It works locally, before publishing.

## Before publishing

The site uses the proposed name "Emery Grahill-Bland" and UCL MSSL affiliation. Please review and edit these as desired.

1. Open `index.html` in a text editor.
2. Update the short biography and the three research project descriptions as needed.
3. Replace the contact placeholder with your chosen professional email and profile links.
4. Replace the publications placeholder with verified papers / presentations, or leave it as a clear placeholder.

All editable places are labelled with `<!-- EDIT HERE -->` comments. Style changes are grouped in the `:root` CSS variables near the top.

## Publish on GitHub Pages

1. Sign into GitHub as `emerygb`.
2. Create a **public** repository named exactly `emerygb.github.io`.
3. In the repository, choose **Add file → Upload files**. Upload `index.html` (optionally also `README.md` and `.nojekyll`) to the **root**, not a subfolder. Commit the files to the repository's default branch (`main` in typical new repositories).
4. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.
5. Once GitHub has deployed the site, visit `https://emerygb.github.io`.

GitHub docs: https://docs.github.com/en/pages/quickstart and https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit later

Edit `index.html` in the repository and commit; GitHub Pages will publish the updated version.

## Privacy

Publishing to GitHub Pages makes the website public. Do not include a personal home address, private datasets, unpublished sensitive research, or contact information you do not want searchable.
